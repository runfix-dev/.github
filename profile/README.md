runfix is the safety net for apps built with AI: Lovable, Bolt, v0, Cursor, Claude Code and Replit. It checks every change, fixes what breaks with proof it works, and stops surprise bills. No code needed.

### What runfix does

- **Safe Deploy.** Every push to your main branch is built and tested in a sandbox. You get a plain verdict on GitHub: safe, risky or blocked.
- **Auto-heal.** When something breaks, runfix makes the error happen again, writes the fix, proves it in a sandbox and opens a pull request for you to approve. It never merges on its own.
- **Fix Lock.** Each fix comes with a test and a rule for your AI tools, so the bug can't sneak back in.
- **Deployment Guard.** runfix compares errors and speed before and after each deploy. If things got worse, switch back to the last good version in one tap.
- **Spend Guard.** Your AI, cloud and hosting costs in one place, with caps, spike alerts and a warning about keys anyone could abuse.
- **Data safety.** Backups with restore tests, point-in-time restore, and a security check that tries to read your data the way a stranger would.
- **Domain health.** DNS, SSL and email settings checked, with alerts when something changes or is about to expire.

### You stay in control

- Every change is a plan card: what changes, what could break and how to undo it. Nothing happens until you say yes.
- Every change can be undone. runfix never merges code or deploys on its own.
- It fails closed. If runfix can't tell whether something is safe, it never says safe.

### Works with

- **Code:** GitHub. GitLab is coming soon.
- **Hosting and data:** Vercel, Netlify, Cloudflare, Supabase and any Linux server.
- **Alerts and approvals:** Slack, Telegram and email.
